
== Klassifisering av datasett - trafikklyssystemet

Trafikklyssystemet er en enkel klassifisering av datasett som deler informasjon i tre tilgangsnivå: _allmenn tilgang_ (grønne data), _betinget tilgang_ (gule data) og _ikke-allmenn tilgang_ (røde data). 

*Grønne data* er data som hvem som helst kan få tilgang til. Tillatte hindringer inkluderer brukerregistrering og forespørsel om API-nøkler, så lenge alle kan få slik registrering og/eller API-nøkler. "Grønne data" som er tilgjengelig for alle og har en åpen lisens, er åpne data.

*Gule data* er data der tilgang som kun kan fås under visse betingelser bestemt av eieren eller tilbyderen. Eksempler på betingelser kan være betaling eller å inngå fortrolighetsavtale. Kategorien inkluderer også data som ennå ikke er kategorisert som allmenn tilgang eller ikke-allmenn tilgang.

*Røde data* er data der som ikke hvem som helst kan få tilgang til, som følge av lovregulerte begrensninger knyttet til sikkerhet, personvern eller lignende. Denne kategorien inkluderer alminnelige personopplysninger, sensitive personopplysninger, taushetsbelagte data og data som har betydning for rikets sikkerhet.

Se Digdirs https://www.digdir.no/2716[Veileder for orden i eget hus] for mer informasjon om trafikklyssystemet.
